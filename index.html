02 · FIRING SYSTEM
MECHANISM → MOTION → CHARACTER
SHOTGUN：每颗节点是一颗独立 sound-design event。
TRACER LANES
one lane = one continuous playback instance
TRACER 不 retrigger selection。每条 lane 连续播放一次 selection；节点只是这条声音沿途经过的 waypoint。加多条 lane 就可以做“双螺旋”。
选择 AMMO 后，FIRE 会把当前 selection 按 event grid 逐颗触发。
